# HHM-Project-# Hispanic Heritage Historical Data Explorer

**Author**: Chinomso Ikwecheghe  
**Focus Country Specialization**: Mexico (MX) & Mexican-Born Immigrants Demographic Dynamics  

## Overview
The **Hispanic Heritage Historical Data Explorer** is a Streamlit application designed to analyze demographic and socioeconomic metrics across Latin America using polynomial regression models (degrees 3–8).

## Mexican Demographic Focus
When selecting **Mexico (MX)**, indicators such as **Net Migration (`SM.POP.NETM`)** and **Crude Birth Rate (`SP.DYN.CBRT.IN`)** provide explicit historical context for demographic shifts and push factors influencing **Mexican-born immigrant populations**.
